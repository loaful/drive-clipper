Moving or renaming your folder in Google Drive

Because Google Drive tracks folders by ID under the drive.file scope, you can freely move or rename WebClips anywhere inside Google Drive without breaking future clips. Use Create / Switch Folder only if you want to start saving into a brand new extension-owned folder.
